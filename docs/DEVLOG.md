# 开发日志

此日志总结了从第一版可玩原型到当前版本的重要演进，便于后续开发者理解设计背景。它不是逐提交的完整 Git 历史。

## v0.9.3 — 五星角色强化与黄金牌标签

- 将流萤强化为高强度空袭角色：火刃、集束空袭、低空扫荡、破韧斩杀与连锁轰炸形成多条构筑路线。
- 所有黄金成长牌加入机制标签，例如「异常」「冰冻」「斩杀」「聚集」「破韧」「追击」「空袭」。
- 保持黄金牌的大视觉反馈，同时限制无意义的全屏常驻覆盖。

## v0.9.0–v0.9.2 — 新角色与牌池闭环

- 新增镜流、刃、丹恒·饮月、托帕&账账、真理医生、黄泉、流萤、飞霄、大黑塔、风堇，共 10 名五星角色。
- 为新角色制作四方向动画、基础技能、5 张普通成长牌和 3 张黄金成长牌。
- 重做新近战角色的底层攻击：通过远程刀光、水浪或龙卷弹进入战斗，减少追敌空转。
- 新增转魄狂暴、亡魂蓄势、水漩涡聚敌、异常次元斩、空袭破韧、大黑塔伤害扩散、小伊卡冲锋等机制。
- 修正召唤与光锥奖励：新角色召唤后固定进入该角色牌池；牌池满后切换到其他可成长角色。
- 主角升级时，队内角色牌池全部满级则不再弹空界面，而是转换为车票。
- 全角色已召唤后，车票仍可用于只抽光锥；无尽层车票上限随层数增长。

## v0.8.x — Combo 与视觉清晰度

- 由纯数值成长转向机制型构筑：冰冻/碎冰、异常/暴击/处决、聚集/范围攻击、破韧/斩杀等跨角色联动。
- 冻结普通敌人时停止其行动，并显示冰蓝材质；首领只延长攻击间隔。
- 将杰帕德的全屏冰封改为扩散冰环，将三月七的全屏攻击改为前方扇形。
- 移除主角大领域、黑洞爆炸以及多种连续波状扩散，压低长期遮屏特效。
- 娜塔莎治疗、杰帕德护盾改为角色身上的小型反馈。
- 丹恒的龙卷风改为冲锋时四向风刃；景元队友脚下光剑只触发一次。
- 修复敌人死亡后预警特效残留。

## v0.7.x — 无尽层与成长节奏

- 第二地图改为有明确击杀目标的无尽试炼：200、500、5000…只怪后出现首领，胜利进入下一层。
- 普通敌人生命按层级 5 倍增长，生成节奏逐层加快；高层首领拥有直线、火雨、瞬移和四向攻击，并先显示预警。
- 伙伴最高 8 级；主角 25 级后经验需求呈指数增长。
- 初始地图车票掉率 5%，无尽地图 1%，并设置层内掉落上限。
- 首领奖励改为只从队伍黄金成长牌中三选一。

## v0.6.x — 光锥成长系统

- 用三张「光锥成长牌」替代旧技能分支界面。
- 每位伙伴拥有 5 张普通牌和 3 张黄金牌；牌可重复获得至 3 级，满级后移出牌池。
- 主角升级时左侧固定主角牌，另外两张来自当前队伍；换人后池自然更新，角色已获得成长永久保留于本局。
- 主角获得旋转剑、方向弹幕、毒弹/异常等可持续构筑能力。
- 车票拾取流程改为：召唤演出完整结束，玩家确认后，再进入附赠成长牌选择。

## v0.4–v0.5 — 第二地图与战斗跟随

- 首领移动到初始地图最右侧，玩家接触后自动激活；击败后可直接前往无尽试炼。
- 新增“星潮旷野”与往返传送，角色、队伍、成长和物品跨地图保留。
- 远程角色扩大索敌和攻击覆盖；移动与施法分离，技能动画不再被行走动画覆盖。
- 丹恒、景元、卡芙卡、希儿增加主动接敌范围。
- 新增角色详情面板、原版立绘和等级角标。

## v0.1–v0.3 — 首个可玩版本

- 完成城镇、道路、敌区、即时自动战斗、首领任务、车票掉落和不重复召唤。
- 完成轨迹列队跟随、战斗离队、战后归队和最多六人编队。
- 加入 11 名初始角色、四方向逐帧动画、小游戏与基础成长。
- 地图扩展至东侧无尽刷怪区，并从平面画面升级为带体积、侧墙、坡面、光照和投影的 2.5D 像素场景。
