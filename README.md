# 星轨 · 失落的回声

一款以《崩坏：星穹铁道》角色为灵感的非官方像素风即时战斗同人游戏。玩家带领最多六名伙伴探索城镇、林间道路与无尽试炼，通过自动战斗、角色协同和可叠加的「光锥成长牌」构筑流派。

> 当前版本：**v0.9.3**。项目仍处于可玩原型阶段，刷新页面会重置进度。

## 玩法概览

- 一张可完成主线任务的初始地图，以及逐层加压的无尽试炼地图。
- 21 名可收集伙伴，四方向行走/攻击动画，最多六人编队。
- 实时自动战斗、轨迹跟随、战后归队、首领预警与多种敌兵。
- 主角升级抽取全队成长牌；车票召唤角色并附赠对应角色成长牌。
- 每名伙伴拥有 5 张普通成长牌和 3 张黄金成长牌，支持叠加、流派标签与跨角色 Combo。
- 冰冻、碎冰、异常、斩杀、聚集、破韧、追击、空袭等机制联动。
- 合影、钓鱼和游艺机小游戏。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `WASD` / 方向键 / 点击地面 |
| 闪避 | `Space` |
| 主角攻击 | `Q` / 鼠标右键 |
| 互动 | `E` |
| 队伍 | `Tab` |
| 暂停 | `Esc` 或右上角按钮 |

点击左下角的角色头像或队伍角色卡，可查看角色资料、技能和已获得的成长牌。

## 本地开发

要求 Node.js 20 或更高版本。

```bash
npm ci
npm run dev
```

提交前运行完整验证：

```bash
npm test
npm run build
```

构建结果位于 `build/`。它使用相对资源路径，可以部署到 GitHub Pages 的项目子目录，也可以用任意静态服务器托管。

## 目录

| 路径 | 用途 |
| --- | --- |
| `dist/` | 游戏源码与静态资源；Vite 以此目录为源码根目录 |
| `dist/engine.js` | 游戏状态、主循环、交互、战斗和地图切换的总控 |
| `dist/render.js` | Three.js 场景、角色精灵和 2D 战斗特效绘制 |
| `dist/ui.js` | HUD、弹窗、召唤、队伍、详情和成长牌界面 |
| `dist/data.js` | 初始 11 名角色的基础数据 |
| `dist/expansion-data.js` | 新增 10 名五星角色及其成长牌 |
| `dist/growth*.js` | 成长牌池、效果、机制标签与主角成长 |
| `dist/*combat.js` | 各类角色、黄金成长、Combo 和新角色战斗逻辑 |
| `dist/world.js` / `dist/trial.js` | 初始地图与无尽试炼 |
| `dist/balance.js` | 经验、掉落、首领、层级等集中数值 |
| `tests/` | Node 逻辑回归测试 |
| `docs/` | 开发日志、架构和 AI 交接说明 |

## 部署

仓库包含 `.github/workflows/pages.yml`。推送到 `main` 后，GitHub Actions 会运行测试、构建项目并部署 GitHub Pages。首次使用时，在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。

更多实现细节和继续开发的规则见 [开发交接文档](docs/HANDOFF.md)，版本演进见 [开发日志](docs/DEVLOG.md)。
